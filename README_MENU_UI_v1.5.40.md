# Aqua.io v1.5.40 — Main Menu Redesign

## Changes
- Redesigned the main menu into clearer premium panels with stronger visual hierarchy.
- Added a hero header with quick-read highlights for fish count, species count, and live ability demos.
- Upgraded the species selection carousel with role labels and larger touch targets.
- Expanded the Ability Lab to show active duration, cooldown, input method, summary, and best-use guidance for each species.
- Kept the 3D ability demo while improving how each fish ability is explained before gameplay.
- Improved menu readability and thumb reach for start, multiplayer, and settings controls.
- Preserved all gameplay systems; this is a UI/UX and presentation pass.
