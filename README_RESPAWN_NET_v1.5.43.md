# Aqua.io v1.5.43 — Respawn Net Visual Upgrade

## Changes
- Upgraded the shared respawn net with richer rim materials, an inner trim ring, and an outer glow ring.
- Added a translucent bag shell over the wireframe bag so the net reads better at a distance.
- Added structural hoops and better vertical strands for a clearer aquarium holding-net look.
- Improved the wooden handle with ferrule and grip details.
- Added subtle animated pulse, sway, and glow during approach and after splashdown.
- Strengthened the drop-ring visibility during releases.
- No gameplay, collision, or respawn timing logic changed.
