# Aqua.io v1.5.39 — Piranha Frenzy Rebalance

- Frenzy base duration: **3.9 → 1.95 seconds** (50% reduction).
- Catch duration extension: **+0.48 → +0.24 seconds** per successful catch.
- Maximum catch-extended remaining duration: **5.3 → 2.65 seconds**.
- Frenzy speed multiplier: **1.12× → 1.0×**, with all catch-stack speed increases removed.
- Hold propulsion to automatically pursue the nearest eligible fish while Frenzy is active; release propulsion to stop. Retargeting on catch remains unchanged.
- Cooldown remains **11 seconds**. Other species, score bonuses, predation and protections unchanged.
- Canonical build uses `aqua_sim.js` and `motion_v2.js` to generate `index.html`; do not hand-edit generated HTML.
