# Aqua.io v1.5.41 — Simplified Species Selection

## User flow
1. Choose Fish/Fisherman.
2. Swipe 13 distinct SVG species portraits.
3. See the existing 3D ability demo, one-line ability summary, strength, and weakness.
4. Choose Free Roam or Last Fish Standing.
5. Use sticky Dive In / Multiplayer buttons.

Advanced ability stats, limitations, cooldown and input instructions remain inside Ability details. Controller sensitivity, flip, and FPS diagnostics are grouped under Controls & settings. How to play is collapsed by default.

## Second pass visuals
- Lightweight distinct vector fish portraits rather than 13 WebGL preview targets.
- Electric Eel demo shows crackling bolt symbols above shocked mini fish.
- Species-specific effect glyphs pulse during active demos; Piranha no longer shows speed streaks because Frenzy provides normal movement speed.
- Angel demo now correctly labels Halo Snare.
- No gameplay simulation, transport, collision, balance, or respawn rule changes.
