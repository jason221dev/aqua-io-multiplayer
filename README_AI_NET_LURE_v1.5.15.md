# Aqua.io v1.5.15 — AI netting and 100-mass fish lures
AI boats close the final gap, pause if line pressure enters the red zone, and trigger a net scoop after roughly 0.22s of physically eligible landing opportunity. Every catch uses canLandFish, remains bounded by actual depth/distance/tension, emits one net event, and displays a longer 1.65s scoop. All lures match a normal starter fish species mesh at mass 100, are visible to the ordinary fish-targeting cue, and remain a fishing hook interaction rather than free biomass. Fishing line/hook/telegraphs remain invisible to fish players. Run npm test, npm run check-sync and npm run test:online. Physical GPU/mobile device rendering remains unverified.
